1. Introduction
This task focuses on using the NumPy library in Python to perform numerical analysis on student marks. A NumPy array was created containing student marks, and different statistical operations were performed on the data.

The main objective of this task is to learn how NumPy can efficiently perform numerical calculations and statistical analysis.
The following values were calculated:
- Mean
- Median
- Maximum
- Minimum
- Standard Deviation
3. Dataset
The following sample student marks were used:
78, 85, 92, 67, 74, 88, 95, 81, 59, 72
These values were stored in a NumPy array.
4. Implementation
The program uses the following NumPy functions:
Function	Purpose
np.array()	Creates a NumPy array
np.mean()	Calculates the average
np.median()	Calculates the middle value
np.max()	Finds the highest value
np.min()	Finds the lowest value
np.std()	Calculates standard deviation


5. Results
The calculated results are:
- Mean: 79.10
- Median: 79.50
- Maximum Mark: 95
- Minimum Mark: 59
- Standard Deviation: 10.45 approximately
6. Result Analysis
The mean of the student marks is 79.10, which represents the average performance of the students.
The median is 79.50, which represents the middle value when the marks are arranged in ascending order.
The highest mark obtained is 95, while the lowest mark is 59.
The standard deviation is approximately 10.45. It indicates how much the student marks vary around the average mark.
